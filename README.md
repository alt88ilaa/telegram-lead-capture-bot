
# 📋 Telegram Lead Capture & Booking Bot

Автоматизированная система сбора лидов и фиксации заявок в Telegram с синхронизацией в Google Sheets и моментальными пуш-уведомлениями администратора.

---

## 📌 Архитектура сценария

Процесс построен на детерминированной маршрутизации событий (Rule-based flow) через оркестратор **n8n**:

1. **Telegram Trigger:** перехват входящих команд и инлайн-кнопок (`callback_query`, `message`).
2. **Маршрутизатор Switch:** распределение логики на основе действий пользователя (выбор направления, запрос информации, оформление заявки).
3. **Google Sheets Sync:** мгновенная запись данных лида (User ID, username, выбранная услуга, таймстемп) в таблицу.
4. **Оповещение:** трансляция собранных данных в чат команды/администратора для быстрой обработки.

[Пользователь] ───► [Telegram Trigger] ───► [Switch Router]
├───► Информационные ответы / Меню
└───► [Google Sheets: Добавление строки]
│
▼
[Push в чат администратора]


---

## 🛠 Стек технологий

* **Платформа автоматизации:** n8n
* **Интерфейс:** Telegram Bot API (Inline Keyboards, Callbacks)
* **База данных / Таблица:** Google Sheets API
* **Формат обмена:** JSON, REST

---

## 🚀 Инструкция по развертыванию

1. Импортировать `workflow.json` в свой инстанс n8n.
2. Подключить учетные данные Telegram Bot API.
3. Настроить интеграцию с Google Sheets (выбрать нужную таблицу и сопоставить колонки: `Username`, `Service`, `Phone/Data`, `Date`).
4. Указать целевой `Chat ID` для пушей администратора в нодах отправки сообщений.
5. Активировать воркфлоу.
